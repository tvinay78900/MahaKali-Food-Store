# MahaKali Food Store

## About the Project
MahaKali Food Store is a web-based online food ordering system designed to make food browsing and ordering simple and convenient for customers.

## Features
- Food Menu Display
- Search Food Items
- Add to Cart
- Update Item Quantity
- Order Placement
- Admin Dashboard
- Order Management

## Technologies Used
- HTML
- CSS
- JavaScript
- Python (Flask)
- MySQL / TiDB
